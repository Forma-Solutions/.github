# Forma Solutions GitHub profile

This repository contains the public organization profile and logo assets for [Forma Solutions](https://github.com/Forma-Solutions).

- [`profile/README.md`](profile/README.md) appears on the organization homepage.
- [`assets/forma-logo.png`](assets/forma-logo.png) is the selected geometric F logo.
- [`assets/forma-avatar.png`](assets/forma-avatar.png) is the 512 × 512 PNG avatar with a white background.

The logo is concept 21 from our design exploration. Both PNG files preserve the selected artwork; they are raster images, not vector files.

Publishing these files does not update the GitHub organization avatar. An organization owner must upload the avatar in the organization's profile settings.
